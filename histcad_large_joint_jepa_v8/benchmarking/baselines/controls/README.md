# Controls

- `random_step_tmcad`: the same untrained STEP encoder on TMCAD.
- `train_tmcad_from_scratch.py`: full STEP encoder plus classifier optimized only with TMCAD labels.
- input graph statistics and train-only PCA: non-neural/classical controls.
